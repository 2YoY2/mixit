**The pipeline (current plan, PerceptAlign only, 2026-08-29):**

```
raw CSI (400 Hz islands, per receiver)
  → CLEAN      (per-packet AGC norm, Hampel, SFO/PDD island detrend, SNR damping)
  → NORMALIZE  (CMN: divide the recording's own static out — room pattern removed,
                unparrotable; the field-standard channel cancellation)
  → STFT       (0.64 s windows, ±2–150 Hz micro-Doppler of the modulation)
  → LIMB RECOGNITION  (scripted actions = clean limb GT; classifiers on
                CMN-STFT features; then separation in this basis)
```
