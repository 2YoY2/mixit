XRF V2 (IMWUT 2025, aiotgroup/XRFV2). Downloaded 2026-08-29 to `~/zerdani/buffer/xrfv2/` (sensors only, ~7.5 GB — the 195 GB Kaggle zip is mostly Kinect videos; per-file download with `kaggle datasets download -f`).

**Census:** 853 sequences, 16 subjects × 3 scenes (Diningroom/Studyroom/bedroom) — **all 16 subjects in all 3 scenes** (full identity cohort). Names = `{subject}_{Scene}_{take}`. WiFi: h5 `samples/<name>/{amp,pha}` float32 (50·T, 3 rx, 3 ant, 30 subc) @50 Hz (200 Hz raw NOT in release — SDP mirror cert-dead; email authors if needed). IMU: 5 devices [left_wrist, right_wrist, left_phone, right_phone, glasses] × 6 ch (accel+gyro) @50 Hz + AirPods @25 Hz. Also pose2d/pose3d/SMPL h5 (limb GT) + TAL/caption annotations (annotations.tar not yet fetched — 2579 files).

**Phase verdict (2026-08-29 probes):** amplitude healthy (dyn 0.028). **Within-antenna spectral phase COHERENT** (aconj subcarrier-avg sig 0.088 — per-antenna complex delay structure usable). **Inter-antenna phase BROKEN** (~0.7 rad/packet jitter; static-beacon scalar recal 0.70→0.44 sig but dyn stays 0.65; offset+slope fit no better) — likely damaged by the release's 200→50 Hz processing. So no fully-coherent 3×3×30 aperture; usable complex rep = **9 per-antenna coherent islands** (amp + within-antenna aconj spectral structure). PA remains the only fully-coherent-phase dataset (conj dyn 0.13).

**Stage-0 limb-fingerprint verdict (2026-08-29, diagnostics/16, 120 recs): NEGATIVE.** v1 (rank-1 IMU-weighted covariance): null 0.65 ≈ cross-limb 0.49–0.69 ≫ stability 0.26–0.34 — global-motion component swamps everything. v2 (top-2 global deflation + interleaved stability): all three collapse together (cross 0.31–0.41, stability 0.26–0.33, null 0.40) → no limb-specific spatial structure findable by this estimator in the island rep at 50 Hz. Limb extraction ICEBOXED for this release; possible revivals: authors' 200 Hz raw with intact inter-antenna phase, or learned bilinear factorization (no cheap control exists though). Body-level scope stands; the deflation finding (global component was the v1 confound) is real and reusable.

**Probe 17 (user's energy-footprint model, dyn_energy ≈ Σ e_i·p_i): partially validates the physics, still no separation.** R²=0.19 (real linear IMU→CSI-energy coupling); physically sensible structure (LW-RW most similar 0.47; leg/pocket footprints most stable 0.40-0.43); but stab (0.29–0.43) ≈ null (0.31) ≈ cross (0.25–0.47) — criterion unmet. Next variant if revived: stationary-segment-conditioned fits. Further variants run 2026-08-29 (room-static whitening per user; differential footprints/common-mode removal): every common-mode killer shifts absolute numbers but never opens a stab≫cross gap (whitened: stab .44–.61 null .53; differential: stab .46–.66 null .55, cross .47–.73).
