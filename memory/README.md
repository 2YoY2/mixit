# memory snapshot (2026-09-01)

A verbatim copy of the assistant's persistent memory directory, committed here
so that **any** model or person can cold start this project from the repo alone.

Read order for a cold start:
1. `../README.md` — the session handoff (state, results, next steps, landmines).
2. `pa-limb-pipeline.md` — the long-form project memory: every probe, every
   verdict, in chronological layers. This is the authoritative record of *why*
   each decision was made; the handoff README is the summary of *where we are*.
3. `MEMORY.md` — one-line index of all memory files.

The other files are reference notes:
- `octonet-dataset.md` — OctoNet specs + the full campaign history (all gates
  failed; dataset deleted 2026-09-01, heartbeat idea closed).
- `xrfv2-dataset.md` — XRF V2 census and phase verdict (deleted 2026-09-01).
- `radear-paper.md` — RemixIT-style teacher/student separation reference.
- `roombody-project-state.md` — the abandoned predecessor project.
- `no-subagents.md` — working preference: no agent fan-outs, work in-session.

These are point-in-time observations. Where a memory names a file, function or
flag, verify it still exists before relying on it — the repo is the ground
truth, memory is the reasoning trail.
